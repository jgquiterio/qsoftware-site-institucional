\# Qsoftware — Site Institucional



\*\*Projeto:\*\* PRJ-0002\_Qsoftware\_Site\_Institucional  

\*\*Empresa:\*\* Qsoftware  

\*\*Versão:\*\* Light  

\*\*Metodologia:\*\* Scrum  

\*\*Gestão e versionamento:\*\* GitHub Projects e Git  

\*\*Status:\*\* Em desenvolvimento



\## Sobre o projeto



Desenvolvimento de um site institucional para apresentar a Qsoftware, seus serviços, diferenciais e informações corporativas, com foco em uma experiência moderna, responsiva e intuitiva.



\## Páginas



\### 1. HOME

\- Apresentação da empresa.

\- Serviços e soluções.

\- Diferenciais.

\- Chamadas para ação.

\- Contato.



\### 2. QUEM SOMOS

\- História e propósito.

\- Missão, visão e valores.

\- Posicionamento institucional.



\## Tecnologias



\- HTML5

\- CSS3

\- JavaScript

\- Bootstrap 5 via CDN
